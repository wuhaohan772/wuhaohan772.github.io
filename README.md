# wuhaohan772.github.io

Personal site — single-page, typography-first, editorial index style.

- **Stack:** Astro, plain CSS, no client framework
- **Edit content:** `src/data/*.json` (site info, projects, experience, education)
- **Edit design:** tokens in `src/styles/global.css`; system spec in `design-system/`
- **Run:** `npm install && npm run dev`
- **Deploy:** push to `main` → GitHub Actions → GitHub Pages
- **Resume:** replace `public/resume.pdf`
